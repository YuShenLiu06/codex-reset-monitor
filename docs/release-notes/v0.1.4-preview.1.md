**怎么开始**

1. 下载适合自己电脑的 ZIP，并完整解压。
2. Mac 双击「Codex 提醒设置」；Windows 双击文件夹内的 `CodexResetInstaller.exe`，不要单独移动它。
3. 跟着窗口连接 GitHub 和飞书。收到安装测试消息后，确认收到，再开启提醒。
