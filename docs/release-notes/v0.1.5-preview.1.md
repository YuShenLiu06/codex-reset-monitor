**怎么开始**

Windows 双击下载的 EXE，准备完成后点“开始设置”；Mac 完整解压 ZIP 后双击「Codex 提醒设置」。按窗口提示连接 GitHub 和飞书，收到安装测试消息后确认，再开启提醒。
