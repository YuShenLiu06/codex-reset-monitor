# 0.1.7 预览版验收范围

本版修复自包含程序申请 GitHub device 码前的证书错误，以及输入授权码后因测试包与目标仓库文件清单不匹配而出现的 NOT_FOUND。默认进度、GitHub App 最小权限和现有提醒开关不变。

## 用户现场确认

用户确认 Mac `0.1.7 test.2` 的前述问题已消失，并明确授权发布。该包 ZIP 为 24,703,205 字节，SHA-256 为 `1e4435afa1f7d3be0cb09cf292a54080126f4b75baa80b2df8eb81e90bc48d90`；构建源码 `b5454b83941f0b67a8e6e736b7e4bdc62fce47a3`，修复分支提交 `677f2d567b17b140c8fac66b2150aece568286fc`，当时核验的部署代码为 `519c2696a5286a388e524d575393acbfe59f070d`。

发布准备只更改构建版本标记、发布校验和说明，未继续修改已验收的安装器业务流程。最终发布包从合并后的同一个 SHA 重建，部署清单改为该最终 SHA，重新运行冻结 worker 验收；旧测试包结果不直接代替最终包结果。
